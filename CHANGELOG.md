# Changelog

## 0.2.1 - 2026-10-21

Settings now save automatically. Changes that would weaken a hard-locked session wait until the lock allows them, with controls to inspect or cancel the pending change.

- Keep the last session type and length, show all start settings together, and choose the current tab as the work tab.
- Keep site access controls visible on blocked pages and add permanent site exclusions from the popup and blocked page.
- Open credit-funded access gates ready to use.
- Keep discarded or unscriptable tabs from preventing a session start. Identify the tab when an unexpected refusal does prevent it.
- Keep a failed initial Sync reported as failed while its outbox waits.
- Update translations, the interactive demo, documentation images and dependency pins.
